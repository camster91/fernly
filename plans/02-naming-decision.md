# Fernly — Brand Name Decision Log

**Status:** Fernly locked 2026-07-10.

---

## The four — final ranking after evidence

### Winner: Fernly

| | |
|---|---|
| **Origin** | Fern + adverb suffix "-ly" |
| **Mental image** | Fern unfurling in low light. Slow, inevitable growth. |
| **App fit** | Daily check-ins + small exercises = living growth. Strong metaphor. |
| **Domain** | `fernly.com` squatted since 2011 (Squarespace registrar, easy buyout) |
| **App Store** | Almost no competition. Clean slot. |
| **App collision** | None — Google search shows only "Fernley" (Nevada city) |
| **Why over Olio** | Olio has 10M+ user food-sharing app + Mental Health Foundation partnership — same brand-collision pattern we rejected in Tide |
| **Test signal** | Listen for: "alive", "growing", "soft" |
| **Kill signal** | "Forgettable", "cute", "for women" — too narrow |
| **Risk** | Slightly twee. Could read as wellness-for-women-only. |

### Runner-up: Olio (rejected — brand collision)

| | |
|---|---|
| **Origin** | Italian — "a miscellaneous collection of things" |
| **Why we wanted it** | Warm, evocative metaphor for scattered thoughts |
| **Why we killed it** | Olio (UK food-sharing app) has 10M+ users + Mental Health Foundation partnership. Direct brand collision in App Store search, social, and word-of-mouth. Same pattern as the Tide rejection. |
| **Lesson** | Beautiful word + brand collision = bad brand. The metaphor survives in marketing copy, not in the name itself. |

### 3. Halcy

| | |
|---|---|
| **Origin** | "Halcyon" (golden, calm, peaceful) cut to four letters |
| **Mental image** | Calm after a storm. Golden hour. Breath held. |
| **App fit** | Modern. App-native. Reads as 2026. |
| **Domain** | `halcy.com` squatted since 2009. |
| **App Store** | Almost zero competition. Very clean. |
| **Test signal** | Listen for: "modern", "calm", "premium" |
| **Kill signal** | "Don't know how to spell it", "sterile", "for old people" |
| **Risk** | Slightly cold/sterile. May read as advanced-user meditation app. |

### 4. Softly

| | |
|---|---|
| **Origin** | Adverb → name. Direct fit to "talk softly to yourself." |
| **Mental image** | A soft voice, low light, a hand on your shoulder. |
| **App fit** | Mirrors the literal product (CBT/ACT self-compassion). |
| **Domain** | `softly.com` squatted since 1998 (very old, valuable). |
| **App Store** | Very clean search. |
| **Test signal** | Listen for: "kind", "gentle", "nice" |
| **Kill signal** | "Passive", "weak", "for babies" |
| **Risk** | Category confusion — could read as adult app, perfume, song. |

## What to do with this list

1. Show all 4 to 5 Gen Z women (target ICP).
2. Ask: "If you saw this on the App Store in Health & Fitness, what do you think it does?"
3. Ask: "Describe it in one word — any word."
4. Ask: "Would you tap on it? Why or why not?"
5. Record exact words. Don't interpret.
6. The name whose description clusters around *calm / warm / friend / quiet* wins.

**Killer signal:** She types it into the App Store *without being asked*.
**Death signal:** She asks how to spell it.
